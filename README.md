# 🎬 IMDB Movies Analysis Using SQL

## 📌 Project Overview
This project focuses on analyzing IMDb movie and director data using SQL and MySQL Workbench. The main objective is to retrieve, filter, organize, and analyze movie-related information to generate meaningful insights about movies, directors, popularity, revenue, and ratings.

## 🎯 Project Objectives
- Analyze IMDB movie and director datasets.
- Retrieve and filter movie and director records.
- Identify popular and highest-revenue movies.
- Analyze female directors.
- Identify directors with the highest number of movies.
- Analyze movie ratings and revenue performance.

## 🛠️ Tools & Technologies
- MySQL
- MySQL Workbench
- SQL

## 📂 Dataset Information

The project contains two main tables:

**1. Movies**
- Movie ID
- Title
- Original Title
- Budget
- Popularity
- Release Date
- Revenue
- Vote Average
- Vote Count
- Director ID

**2. Directors**
- Director ID
- Director Name
- Department
- Gender
